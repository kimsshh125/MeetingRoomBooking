# 산학연실 예약

산학연실1·2·3 회의 공간을 예약하고 현황(일간 시간표, 월간 달력)을 확인하는 페이지입니다.
로그인 없이, 링크를 아는 사람은 누구나 예약하고 취소할 수 있습니다.
예약 데이터는 Firebase(Firestore)에 저장되고, 페이지는 GitHub Pages로 공개합니다.

## 주의

링크를 아는 사람은 누구나 예약을 만들고 지울 수 있습니다. 회사 내부에서만 링크를 공유하세요.
저장소를 Public으로 두면 코드의 Firebase 설정값이 공개됩니다. 이 값은 비밀번호가 아니지만,
아래 3단계 규칙이 사실상 접근 제한 역할을 한다는 점을 알고 쓰세요.

## 1. Firebase 프로젝트 만들기

1. https://console.firebase.google.com 에 구글 계정으로 접속합니다. (관리자 한 명만 하면 됩니다.)
2. **프로젝트 추가**를 누르고 이름을 정합니다. 예: `sanhak-booking`
3. 구글 애널리틱스는 꺼도 됩니다. **프로젝트 만들기**를 누릅니다.

## 2. Firestore 데이터베이스 만들기

1. 왼쪽 메뉴에서 **빌드 → Firestore Database → 데이터베이스 만들기**를 누릅니다.
2. 위치는 `asia-northeast3 (서울)`을 고릅니다. 한 번 정하면 바꿀 수 없습니다.
3. 보안 규칙 모드는 **프로덕션 모드로 시작**을 고르고 만듭니다.

## 3. 규칙 붙여 넣기

1. Firestore Database 화면 위쪽의 **규칙** 탭을 엽니다.
2. 안의 내용을 모두 지우고 아래를 붙여 넣은 뒤 **게시**를 누릅니다.

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /bookings/{id} {
      allow read, write: if true;
    }
    match /slots/{id} {
      allow read, write: if true;
    }
  }
}
```

이 규칙은 로그인 없이 누구나 읽고 쓸 수 있게 합니다. "테스트 모드"로 시작하면 30일 뒤 자동으로 막히므로 위 규칙을 직접 넣어야 합니다.

## 4. 웹 앱 등록하고 설정값 복사하기

1. 프로젝트 개요 화면에서 `</>` (웹) 아이콘을 누릅니다.
2. 앱 닉네임을 적고(예: `booking-web`) **앱 등록**을 누릅니다. 호스팅 설정은 체크하지 않습니다.
3. 화면에 나오는 `firebaseConfig = { ... }` 안의 값을 복사합니다.
4. `index.html` 파일을 열어 `YOUR_...`로 적힌 `firebaseConfig` 부분을 복사한 값으로 바꿉니다.

## 5. GitHub에 올리고 공개하기

1. GitHub 저장소 화면에서 **Add file → Upload files**로 `index.html`을 올립니다. 이미 있으면 같은 이름으로 덮어씁니다.
2. 파일 이름은 반드시 `index.html`이어야 주소로 바로 열립니다.
3. **Commit changes**를 누릅니다.
4. 저장소의 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main`, 폴더를 `/ (root)`로 정하고 **Save**를 누릅니다.
5. 1~2분 뒤 같은 화면에 주소(`https://계정.github.io/저장소명/`)가 나옵니다. 이 링크를 동료들에게 공유합니다.

## 동작 방식

- 예약은 30분 단위(08:00–22:00)입니다. 30분 칸마다 문서를 하나씩 만들어 확보하므로, 같은 시간에 두 사람이 동시에 눌러도 한 명만 예약됩니다.
- 예약자 이름은 폼에 직접 입력하고 이 기기에 기억됩니다.
- 시간표의 굵은 테두리는 이 기기(브라우저)에서 예약한 건입니다.
- 조회는 지난달 1일부터 가능합니다.

## 문제가 생기면

- 화면 위에 "Firebase 설정값이 아직 입력되지 않았습니다"가 뜨면 4단계를 확인하세요.
- "읽기 권한이 없습니다"가 뜨면 3단계 규칙이 게시됐는지 확인하세요.
- 예약 버튼이 계속 비활성화되면 화면의 빨간 안내 문구를 확인하세요.
